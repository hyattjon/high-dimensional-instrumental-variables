results¶

All four estimators return a subclass of IVResult.

class high_dimensional_instrumental_variables._results.IVResult(beta: ndarray, vcov: ndarray, leverage: ndarray, fitted_values: ndarray, tstats: ndarray, pvals: ndarray, cis: ndarray, root_mse: float, r_squared: float, adjusted_r_squared: float, f_stat: float, f_pval: float, first_stage_f: float | ndarray, first_stage_f_pval: float | ndarray)¶

Results of a jackknife IV regression.

The coefficient vector is ordered [constant, endogenous regressors..., controls...].

beta¶

Estimated coefficients.

Type:

ndarray, shape (P,)

vcov¶

Heteroskedasticity-robust covariance matrix of beta (a sandwich estimator following Poi (2006), with no finite-sample correction).

Type:

ndarray, shape (P, P)

leverage¶

Leverage (diagonal of the first-stage projection matrix) of each observation.

Type:

ndarray, shape (N, 1)

fitted_values¶

Ordinary first-stage fitted values of the endogenous regressors, before the jackknife correction.

Type:

ndarray, shape (N, L)

tstats, pvals

t-statistics and two-sided p-values, using a t distribution with N - P degrees of freedom.

Type:

ndarray, shape (P,)

cis¶

95% confidence intervals (lower, upper), from the same t distribution.

Type:

ndarray, shape (P, 2)

root_mse¶

Root mean squared error, sqrt(RSS / (N - P)), with residuals Y - X beta from the structural equation.

Type:

float

r_squared, adjusted_r_squared

1 - RSS / TSS and its degrees-of-freedom adjustment, computed from the structural residuals. For IV this is not a goodness-of-fit measure: it can be negative and its value is not comparable to an OLS R-squared.

Type:

float

f_stat, f_pval

Heteroskedasticity-robust Wald test that all coefficients except the constant are zero, reported as an F-statistic (Wald / (P - 1)) with (P - 1, N - P) degrees of freedom.

Type:

float

first_stage_f, first_stage_f_pval

Partial first-stage F-test (classical, homoskedastic) that the excluded instruments jointly explain each endogenous regressor, given the constant and controls. A float for one endogenous regressor, otherwise one entry per regressor. The usual rule of thumb is that F < 10 signals weak instruments.

Type:

float or ndarray

Notes

se is the vector of standard errors, sqrt(diag(vcov)). standard_errors is a deprecated alias of vcov (it has always been the covariance matrix, not the standard errors).

property se¶

sqrt(diag(vcov)).

Type:

Standard errors of beta

summary()¶

Print a regression table (coefficients, robust standard errors, t-tests, confidence intervals) and fit statistics.
